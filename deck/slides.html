Brief about the idea

One decision loop turns a forecast into a sale, before the write-off happens.

1Capture a pallet photo
2Sense nightly gaps, in rupees
3Plan a play; the estimator owns the rupees
4Approve with a holdout; feed it back to the forecast
5Engage consenting customers, in their language
6Measure treated vs holdout, 95% CI
ThemeTaal forecasts stock per SKU and node nightly, with festival effects, and drafts human-approved offers.

List of features

Six capabilities, gated by rules a model never touches.

Vision intake

Photograph a pallet; dates and counts come back with confidence. Low confidence goes to a person.

Nightly Sense

Per-SKU, per-node forecasts. Six gap types, each with rupees and a deadline.

Planner Agent

ADK LoopAgent, max 3 iterations, six deterministic tools; a Cost Governor picks the gaps.

Approve + assignment

A human approves. Holdout by hash; offers go to treated customers only.

Customer Agent

Grounded in stock, offers and consent. Orders through an in-process MCP tool.

Measure

Treated vs holdout, 95% CI. Priors update from the counts.

Technologies used

Google Cloud AI stack, benchmarked before use.

Gemini 3.5 Flash

On Vertex AI: vision intake, Planner Agent and Customer Agent.

Google ADK

LoopAgent (max 3), 6 deterministic tools and 8 guardrails around every play.

BigQuery

AI.FORECAST benchmarked and run nightly; AI.GENERATE_TABLE writes offer copy. Judges see the local forecaster.

Firestore

Practitioner feedback store, live in the deployed service.

Cloud Run

Services scale to zero; Cloud Run Jobs and Cloud Scheduler run Sense and Measure nightly.

Next.js · FastAPI · MCP

Play Desk, phone view and chat on Next.js; API on FastAPI; orders via an in-process MCP tool.

DeployGitHub Actions runs verify, then deploys to Cloud Run on every merge to main.

User guide

Three people, three screens, one approved play.

Planner

/desk
  1. 1Open the Play Desk and pick a gap.
  2. 2Check the guardrails and counterfactuals.
  3. 3Click Approve. The forecast moves.

Node manager

/phone
  1. 1Photograph a pallet, or tap a sample.
  2. 2Confirm the rows read below 0.7 confidence.
  3. 3Approve the play from the gap card.

Customer

/chat
  1. 1Open the chat. It starts with "Any offers today?".
  2. 2Ask about a product. You see a stock band, not a count.
  3. 3Send STOP to withdraw consent.
Badges. LIVE: a real call this visit. REPLAY: stored output replayed. SYNTHETIC: fabricated demo data. "Recorded from Gemini": a dated real model run.

Longevity · running it for real

What it takes to run past the competition.

Production path

  • Least-privilege accounts replace the deploy owner.
  • CI uses a stored key. Move to workload identity.
  • Secrets sit in a managed store.
  • Model IDs pinned with retirement dates: gemini-3.5-flash live, Flash-Lite fallback; the previous model retires 20 Oct 2026.

Scalability

  • Measured: Sense 3.8 s; planner re-plan 27 to 30 s live; chat 4.5 to 6.9 s.
  • Estimate: 20,000 SKUs, 500 nodes.estimate
  • Breaks first: the planner queue.

Feasibility

  • Buyer: category or supply-chain head. Fee per node or rupee share.
  • Pilot: 50 to 60 testers, one week, not yet run.
  • Run cost: ₹486 a month, measured usage, not a bill.
  • Estimates: ₹200 to 500 (Micro), ₹2,500 to 5,000 (Mid), ₹1 to 2 lakh (Large).estimate
