# Learning curve

What we measured, what that showed, what we changed, and what the next measurement said. Every row cites a committed file; figures are copied from it. Pre-switch rows ran on `gemini-2.5-flash`; the live model since 10 Oct 2026 is `gemini-3.5-flash`. Rows are in date order and several are reversals: a change that made one number worse is listed as such.
