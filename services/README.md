# Services

`api/`: FastAPI service behind the web app (`make api`, port 8080). Contract: `docs/openapi.yaml`
(generated by `make openapi`). Every request runs in the visitor's copy-on-write sandbox
(`X-Taal-Visitor` header or `taal_visitor` cookie); `/reset` clears that sandbox only. Live
paths: `/approve` (assignment, offers, regressor rows, single-series re-forecast), `/rerun`
(planner with an edited policy), `/chat` (SSE envelopes), `/capture` and `/capture/confirm`,
`/execution`, `/measure`. Spec §5.4, §5.6, §10; checklists `approve_assignment.md`, `event_log_replay.md`.
